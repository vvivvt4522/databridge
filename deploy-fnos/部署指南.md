# fnOS 部署指南（服务器迁移到 NAS）

把 DataBridge 服务器从台式机迁到 fnOS 后：台式机、手机、iPad 全部变成客户端，只要 fnOS 笔记本开着，任何两台设备之间都能互传，谁关机都不影响别人。

准备工作：把项目里的 `deploy-fnos` 文件夹整个复制到 fnOS 的文件管理器里（比如放到 `/vol1/1000/databridge-deploy/`），并把项目根目录的 `server` 文件夹、`web` 文件夹、`package.json` 也复制进 `deploy-fnos` 文件夹（保持同名）。

## 方式一：裸机部署（推荐，最简单）

1. fnOS 设置里打开 **SSH**
2. 电脑上用终端连接：`ssh 你的fnOS用户名@NAS的IP`（密码同 fnOS 登录密码）
3. 进入目录并执行脚本：

```bash
cd /vol1/1000/databridge-deploy
sudo bash deploy.sh
```

4. 结束时会打印 **三端连接地址**（`http://NAS的IP:8322/?t=配对码`），复制保存

> 服务已注册为系统服务：开机自启、崩溃自动重启。
> 常用命令：`systemctl status databridge` 看状态 / `systemctl restart databridge` 重启。

## 方式二：Docker 部署（如果 fnOS 装了 Docker）

1. 确认 `deploy-fnos` 文件夹里有 `server`、`web`、`package.json`、`docker-compose.yml`
2. fnOS 的 Docker 应用 → Compose → 新建 → 选择该文件夹的 `docker-compose.yml` → 启动
3. 日志里出现 `DataBridge v0.2 server ready` 即成功；地址同样是 `http://NAS的IP:8322/?t=...`
   （token 在 `server/data/config.json` 里查看）

## 三端重新配对

| 端 | 操作 |
|---|---|
| 安卓 | 打开 App → 会自动搜索到 NAS（名字显示为 fnOS 主机名）→ 点击连接；或齿轮 → 手动输入地址 |
| iPad | Safari 打开新地址（旧书签地址失效，重新粘贴一次即可） |
| PC | 桌面版托盘右键 → 连接服务器 → 设置远程服务器地址… → 粘贴地址，应用会自动重启并切换；以后也可在"本机/远程"之间切换 |

## 迁移旧数据（可选）

把台式机 `C:\Yesnoi\Y-zcode\三端数据互通工具\server\data\` 整个文件夹复制到 fnOS 的 `/opt/databridge/server/data`（覆盖），历史传输记录和配对码就都迁过去了（配对码不变的话，三端甚至不用重新配对）。
